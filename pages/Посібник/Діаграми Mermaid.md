# Діаграми Mermaid

Mermaid дозволяє малювати схеми **текстом**. Замість графічного редактора ви пишете код — і отримуєте картинку. Ідеально для механік гри.

## Як вставити

Оформіть блок коду з мовою `mermaid`:

````markdown
```mermaid
graph TD
    A[Початок] --> B[Кінець]
```
````

## Тип 1: Блок-схема (graph / flowchart)

```mermaid
graph TD
    A[Початок] --> B{Умова?}
    B -->|Так| C[Дія 1]
    B -->|Ні| D[Дія 2]
```

Синтаксис:
- `A[текст]` — прямокутник.
- `B{текст}` — ромб (рішення).
- `X --> Y` — стрілка.
- `X -->|підпис| Y` — стрілка з підписом.
- Напрямки: `TD` (згори вниз), `LR` (зліва направо), `TB`, `RL`, `BT`.

## Тип 2: Послідовність (sequenceDiagram)

```mermaid
sequenceDiagram
    participant Гравець
    participant Авто
    Гравець->>Авто: Натиснув P
    Авто-->>Гравець: Музика лунає
```

- `->>` — стрілка з запитом.
- `-->>` — пунктирна (відповідь).
- `loop ... end` — цикл.

## Тип 3: Стани (stateDiagram-v2)

```mermaid
stateDiagram-v2
    [*] --> Готово
    Готово --> Перегляд
    Перегляд --> [*]
```

## Тип 4: Класова діаграма (classDiagram)

```mermaid
classDiagram
    class Wiki {
        +pages
        +loadPage()
    }
```

## Тип 5: Гант (gantt)

```mermaid
gantt
    title План
    section Етап 1
    Робота :done, 2026-01-01, 7d
```

## Тип 6: Сутність–зв'язок (erDiagram)

```mermaid
erDiagram
    PAGE ||--o{ CATEGORY : належить
```

## Тип 7: Кругова (pie)

```mermaid
pie title Розподіл
    "Авто" : 45
    "UI" : 30
    "Інше" : 25
```

## Поширені помилки

- **Одна друкарська помилка** — і вся діаграма не збудується.
- Не вставляйте Markdown/HTML усередину блоку `mermaid`.
- Перевіряйте дужки та стрілки. Тестуйте на mermaid.js.org.
