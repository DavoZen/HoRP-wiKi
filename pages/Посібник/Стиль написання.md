# Стиль написання статей

Однотипність важливіша за красномовство. Цей посібник встановлює правила того, **як** писати, незалежно від теми.

## Мова та термінологія

- Пишіть **українською**.
- Назви ігор/модів/систем — як у грі (напр. `HoRP`, `A-Chassis`).
- Технічні терміни англійською залишайте як є: `HUD`, `studs`, `tool`, але пояснюйте їх українською при першій згадці.
- Клавіші пишіть у зворотних лапках: `` `P` ``, `` `U` ``.

## Тон

- **Нейтральний, довідковий.** Без "мені подобається", "круто".
- Звертайтесь до читача на "ви": "Ви відкриваєте панель".
- Факти, не оцінки. Замість "дуже крута фіча" — "дозволяє відтворювати музику".

## Структура

Дотримуйтесь каркаса:

```markdown
## Огляд
## Як користуватися
## Інтерфейс / Елементи
## Можливі проблеми
## Поради
## Пов'язані статті
```

## Форматування

- Заголовки — від `##`.
- Списки — для переліків; таблиці — для "властивість/значення".
- Виділяйте **важливе** жирним, але не переборщуйте.
- Використовуйте `==підсвічування==` для критичних попереджень.
- Складні процеси — у вигляді Mermaid-схеми.

## Назви файлів

- Без великих літер на початку, без спецсимволів: `програвач касет.md`.
- Пробіли допустимі, але у посиланнях замінюйте на `%20`.
