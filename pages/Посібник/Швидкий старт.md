# Швидкий старт для автора

Не хочете читати величезний підручник? Ось мінімум, щоб створити першу статтю. Деталі — у [Підручнику автора](Підручник%20автора).

## Крок 1. Створіть файл

Створіть текстовий файл із розширенням `.md` у потрібній папці. Назва = назва теми.

```
pages/Машини/Механіки/Мій файл.md
```

## Крок 2. Додайте службовий блок (front matter)

Перші рядки файлу:

```markdown
---
title: Мій файл
category: Машини/Механіки
summary: Коротко про що стаття.
---

```

> Три дефіси `---` зверху і знизу обов'язкові.

## Крок 3. Напишіть текст

Починайте з `##` (не з `#`):

```markdown
## Огляд
Короткий опис теми.

## Деталі
- Пункт один
- Пункт два
```

## Крок 4. Перевірте

- [ ] Файл `.md`?
- [ ] Є `title` і `category`?
- [ ] Тіло з `##`?
- [ ] Порожній рядок між блоками?

## Готово

Збережіть — стаття готова. Детальніше про кожен елемент читайте в [Підручнику автора](Підручник%20автора).
