# HoRP-wiKi

Вільна енциклопедія спільноти **HoRP** (Хриплинська область Role Play) — багатоплатформної рольової гри в жанрі симулятора життя на платформі Roblox.

> Цей репозиторій містить статичну вікі, яка автоматично публікується через GitHub Pages.

## Про проєкт

HoRP — це ремейк проєкту **Хриплин RP** (запущений 26.08.2023), офіційно започаткований 5 лютого 2025 року. Гра локалізована українською мовою та відтворює село Хриплин у 2015 році. Стан розробки — альфа-версія.

HoRP-wiKi створена, щоб зібрати документацію по механіках гри, автомобілях, інтерфейсі та версіях у зручному для гравців вигляді.

## Технології

- Статичний сайт: `index.html` + `style.css` + `script.js`
- Рендеринг Markdown через [marked](https://marked.js.org/) та [markdown-it](https://github.com/markdown-it/markdown-it)
- Діаграми [Mermaid](https://mermaid.js.org/), підсвітка коду [Prism](https://prismjs.com/)
- Статті зберігаються як `.md` файли у папці `pages/` і підвантажуються напряму з репозиторію через GitHub API

## Формат статті

Кожна стаття — це Markdown-файл із необов'язковим YAML front matter на початку:

```markdown
---
title: Назва статті
category: Категорія
summary: Короткий опис для списків і пошуку
author: Автор
created: 2026-07-05
tags: [тег1, тег2]
status: Стабільна
---

## Огляд

Текст статті...
```

Підтримувані поля front matter:

| Поле | Призначення |
|------|-------------|
| `title` | Заголовок статті (інакше береться назва файлу) |
| `category` | Категорія (інакше визначається за папкою) |
| `summary` | Короткий опис для попереднього перегляду |
| `author` | Автор статті |
| `created` | Дата створення |
| `tags` | Список тегів |
| `status` | Статус документації (напр. *Стабільна*, *Чернетка*) |

Категорія визначається автоматично за назвою підпапки у `pages/`, якщо не вказана явно.

## Як додати статтю

1. Створіть `.md` файл у потрібній підпапці `pages/` (підпапка = категорія).
2. Додайте front matter (рекомендовано).
3. Напишіть вміст у Markdown (підтримуються таблиці, цитати, блоки коду, Mermaid).
4. Зробіть коміт — зміни з'являться на GitHub Pages автоматично.

Посилання між статтями вказуйте відносно папки `pages/`, наприклад:
`[Програвач касет](Машини/Механіки/Програвач%20касет)`.

> 📘 **Докладний посібник для авторів:** [pages/Посібник/Підручник автора.md](pages/Посібник/Підручник%20автора.md) — величезна документалка з написання `.md` файлів: синтаксис Markdown, front matter, усі підтримувані елементи (списки, таблиці, код, Mermaid, кольори, бейджі, спойлери, математика, емодзі), компроміси, обмеження та чек-лист. Розраховано на повних новачків.
